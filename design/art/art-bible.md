## Section 1: Visual Identity Statement

### 总纲法则

> **「万物蓄势——画面中没有静止的像素，每个元素都在预告它下一秒的动作」**

这是对「每一帧都是攻击预告」的扩展。战斗场景中，敌人的姿态是蓄力的、刀刃的反光是挥斩的前兆；探索场景中，废墟在倾斜中暗示即将崩塌、阴影在摇曳中暗示即将移动。即便是UI界面，按钮也应有微妙的呼吸感。

**判断标准**：指着你画面中的任何一个元素，问"它看起来像即将做什么？"——如果答不上来，这个元素就需要重新设计。

猫眼金 `#ECC94B` 是这条法则的视觉锚点：无论画面多么混乱，金色永远在说"这里是安全的，这里属于你"。

---

### 原则 A：形态即命运

> **角色的剪影就是它的战斗宣言——尖角宣告攻击意图，曲线宣告灵动本质。**

| 项目 | 内容 |
|------|------|
| **设计测试** | 当角色/敌人的形态设计在"可爱"与"危险"之间犹豫时：用剪影传达战斗身份。所有攻击性元素（爪、刃、刺）用三角形和锐角；所有灵动感元素（身体、尾巴、耳朵）用流畅曲线。两者的**比例**定义了角色在"可爱—危险"光谱上的位置。 |
| **服务于** | 支柱1「猫科战斗美学」+ 支柱4「可爱与危险的视觉反差」 |
| **应用范围** | 角色设计、敌人设计、Boss设计 |

**示例**：主角猫——身体轮廓用圆润曲线（50%可爱），但耳朵尖端、尾巴末端、武器持有处都有锐角收束（50%危险）。尖与圆在同一个形体上渐变过渡。

---

### 原则 B：新旧共生于一帧

> **环境是时间断层的X光片——每个场景必须同时呈现文明毁灭前的余温与毁灭后的荒芜。**

| 项目 | 内容 |
|------|------|
| **设计测试** | 当场景构图在"纯粹废墟"与"纯粹机械"之间犹豫时：每个画面必须同时包含旧世界的有机残留（曲线、锈橙 `#C05621`、可辨认的人类文明痕迹）和新侵占的机械结构（直角、钢灰 `#4A5568`、变异生物的改造痕迹）。缺少任一侧，场景就沦为单调的"后末日灰"。 |
| **服务于** | 支柱5「叙事融入世界」+ 支柱2「机制探索回报」 |
| **应用范围** | 关卡设计、环境美术、背景叙事 |

**示例**：废弃便利店——货架歪斜但招牌仍可辨认（旧世界余温），收银台上盘踞着变异生物的管线巢穴（新世界侵占），角落一台仍在闪烁的自动售货机暗示这里曾有最后一批顾客。

---

### 原则 C：色彩即语法

> **颜色不是装饰而是语言——每种颜色有且只有一个语义，玩家必须在0.3秒内通过颜色完成关键判断。**

| 项目 | 内容 |
|------|------|
| **设计测试** | 当多种颜色竞争玩家注意力时：按信息优先级分配颜色权重。第一优先——猫眼金 `#ECC94B` 标记玩家自身与安全区域；第二优先——信号红 `#E53E3E` 标记敌人威胁与即时危险；第三优先——毒绿 `#48BB78` 标记变异特征。装饰性颜色（锈橙、霓虹紫、月光蓝）填充氛围但绝不抢占前三者的视觉权重。 |
| **服务于** | 支柱1「猫科战斗美学」 |
| **应用范围** | UI设计、视觉反馈、特效设计、色彩层级管理 |

**0.3秒验证法**：在高速战斗截图中，玩家能否在0.3秒内仅通过颜色判断——"我在哪（金色）、威胁在哪（红色）、出路在哪（蓝色）"？如果不能，配色方案需要调整。

---

### 法则—原则协同关系

```
              ┌─────────────────────────┐
              │   总纲：万物蓄势          │
              │  "每个像素预告下一秒"     │
              └─────────┬───────────────┘
           ┌────────────┼────────────┐
           ▼            ▼            ▼
    ┌──────────┐ ┌──────────┐ ┌──────────┐
    │ A:形态   │ │ B:新旧   │ │ C:色彩   │
    │ 剪影=命运│ │ 时间断层 │ │ 颜色=语法│
    └────┬─────┘ └────┬─────┘ └────┬─────┘
         │            │            │
    角色·敌人      关卡·环境      UI·特效
    战斗设计       探索设计       反馈设计
```

三条原则覆盖三个不重叠的设计领域：
- 不确定一个角色该长什么样 → **原则A**
- 不确定一个场景该怎么构图 → **原则B**
- 不确定一个界面/特效该用什么颜色 → **原则C**

## Section 2: Mood & Atmosphere

### 情绪弧线总览

```
标题 → 探索 → 发现 → 战斗 → Boss → 胜利 → 枢纽 → 死亡
悬念    孤寂   惊奇   锐利   压迫   释放   温暖   断裂
```

**核心对比轴**: 枢纽站（最暖3200K）⟷ Boss战（最冷7500K），温差最大形成情绪锚点。

### 色彩语义速查

| 色彩 | 色值 | 语义 | 使用约束 |
|------|------|------|---------|
| 琥珀橙 | `#D4913A` | 旧世界余温、安全残留 | 仅安全/回忆相关 |
| 钢青灰 | `#6B8A9E` | 新世界荒芜 | 大面积环境基调 |
| 荧翠绿 | `#48BB78` | 生命、安全通行 | 仅安全区与可交互物 |
| 警兆红 | `#E53E3E` | 即时威胁 | 仅敌人攻击判定 |
| 幽紫 | `#9B5AE8` | 神秘、隐藏 | 隐藏要素提示 |
| 辉金 | `#ECC94B` | 成就、稀有 | 极稀缺使用（玩家/安全统一色） |

### 各状态定义

| 状态 | 情绪目标 | 色温 | 对比度 | 能量 | 独特标识 |
|------|---------|------|--------|------|---------|
| **探索** | 孤寂中的好奇 | 冷6500K+ | 中低 | 沉思缓行 | 漂浮尘埃粒子 |
| **战斗** | 锐利的舞蹈 | 极冷7500K | 高 | 爆发脉冲 | 速度残影+警兆红预显 |
| **Boss-1威压** | 巨兽面前 | 极冷 | 极高 | 窒息 | Boss阴影吞噬战场 |
| **Boss-2焦灼** | 共振 | 冷暖振荡 | 高 | 焦灼 | 碎片悬浮 |
| **Boss-3殊死** | 最后一搏 | 崩溃 | 极高→崩 | 殊死 | 像素碎裂+色差 |
| **发现** | 猫咪打开宝箱 | 暖3500K | 中 | 静止惊叹 | 遗物自发光 |
| **枢纽** | 回到窝里 | 最暖3200K | 低 | 慵懒舒适 | 层叠暖光源(4-5个) |
| **死亡** | 影子消散 | 灰度 | 消褪 | 骤停 | 影化消散（眼睛最后熄灭） |
| **胜利** | 晨曦破晓 | 暖金4000K | 中→低 | 高峰舒缓 | 辉金光流填充 |
| **标题** | 门槛上的猫 | 冷暖分屏 | 中 | 蓄势待发 | 交界剪影(半暖半冷) |

### 状态间转换规则

| 转换 | 过渡方式 | 时长 |
|------|---------|------|
| 探索 → 战斗 | 画面推近 + 色温骤冷 + 饱和度提升 | 0.5秒 |
| 战斗 → 探索 | 最后击杀hitstop → zoom out → 色温回暖 | 1.0秒 |
| 任意 → Boss | Boss阴影从边缘渗入，吞噬环境光 | 2.0秒 |
| Boss → 胜利 | 全屏白闪 → 金色光流扩散 | 3.0秒 |
| 任意 → 死亡 | 饱和度线性归零 + 光源逐一熄灭 | 1.5秒 |
| 死亡 → 枢纽 | 幽紫粒子重组为猫形 → 地铁站暖光渐入 | 2.0秒 |
| 探索 → 发现 | 幽紫门框微光 → 进入后琥珀金光爆发 | 0.8秒 |
| 标题 → 游戏 | 猫起身行走 → 画面跟随过渡 | 3.0秒 |

### 关键视觉细节

- **探索**：背景废墟呈骨架感，天空占60%，猫在下方1/3处。尾巴尖端微微发光（猫科感知）
- **战斗**：画面推近5%，猫移动留2-3帧半透明残影。完美闪避时残影变金色。击杀最后敌人hitstop 0.1秒
- **Boss战**：三阶段——阴影覆盖→环境碎片悬浮→背景像素碎裂剥落
- **发现**：隐藏房间饱和度比外部高，背景细节丰富3倍。猫瞳孔放大
- **枢纽**：饱和度比探索+20%。至少4-5个暖光源叠加。地面有猫爪印磨损痕迹
- **死亡**：猫身体变黑色剪影→墨水般从边缘溶解→碎片向上飘散（像烟）。残影粒子被风吹向地铁站方向
- **胜利**：光流填充时废墟短暂显示旧世界面貌3秒（原则B极致表达）
- **标题**：猫坐在冷暖交界线上，半暖半冷。尾巴2秒抽动一次，耳朵3秒转向一次

## Section 3: Shape Language

### 1. 角色剪影哲学
**缩略图可读性测试**：所有角色在32×32px下必须可辨识阵营与职能。

| 原型 | 核心形态 | 辨识特征 |
|------|---------|---------|
| 突击喵 | 倒三角+前倾锐角 | 武器轮廓超出身体 |
| 侦察喵 | 流线椭圆+长尾弧 | 尾巴占画面1/3 |
| 重甲喵 | 方正块状+宽底座 | 肩甲宽度≥身高60% |
| 技工喵 | 圆形主体+不对称工具 | 单侧大工具 |

**法则**：锐角=攻击性，曲线=敏捷，方块=防御。主角50/50=圆润身体+尖锐武器/耳朵。

### 2. 环境几何
主导：有机+残破几何。自然侵蚀弧线包裹人造硬边。
- 安全区域：圆角主导
- 危险区域：裸露钢筋尖角
- 探索奖励区：独特有机形态打破规律

### 3. UI形态语法
低对比圆角矩形（8px圆角），与世界形成「观察窗」式区隔。
- 血条：瞳孔状椭圆
- 技能图标：六边形
- 对话框：猫耳顶部装饰
- **法则**：UI永远不用锐角，HUD是「安全港」视觉语言

### 4. 英雄形态 vs 支撑形态
- 吸引视线：高饱和+锐利边缘+动态倾斜（最多3个）
- 退后：低饱和+模糊边缘+水平对齐

## Section 4: Color System

### 1. 主调色板

| 色彩 | 色值 | 语义角色 |
|------|------|---------|
| 琥珀橙 | `#D4913A` | 安全/温暖 |
| 钢青灰 | `#6B8A9E` | 中立/环境 |
| 荧翠绿 | `#48BB78` | 生命/治愈 |
| 警兆红 | `#E53E3E` | 危险/伤害 |
| 幽紫 | `#9B5AE8` | 神秘/技能 |
| 辉金 | `#ECC94B` | 奖励/稀有（统一色=玩家/安全） |

**铁律**：每色只承担一个语义，绝不在同一画面中复用。

### 2. 使用规则
- 可交互物体边缘有对应语义色的2px辉光描边
- 敌人受击闪白0.1s，血条始终警兆红
- NPC对话框边框琥珀橙，敌对边框警兆红

### 3. 生态区色温

| 区域 | 色温 | 主调 |
|------|------|------|
| 锈蚀荒原 | 5500K | 钢青灰+铁锈橙 |
| 荧光深林 | 6000K | 幽紫+荧翠绿 |
| 冰晶废墟 | 7500K | 冷蓝+白 |
| 熔岩裂隙 | 4000K | 警兆红+辉金 |
| 静默沙海 | 6500K | 钢青灰+沙黄 |
| **枢纽营地** | **3200K** | **琥珀橙主导（无警兆红）** |

### 4. UI调色板
- 背景：#1A1A2E（深靛黑）或 #F0EDE5（旧纸白）
- 文字：#E8E4DC（米白），标题用辉金
- 按钮：默认钢青灰，悬停琥珀橙，确认辉金，取消警兆红
- UI不使用荧翠绿和幽紫作大面积色，仅作状态指示

### 5. 色盲安全冗余

| 语义色 | 形状备份 | 声音备份 |
|--------|---------|---------|
| 警兆红 `#E53E3E` | ▼三角 | 低沉警告音 |
| 荧翠绿 `#48BB78` | ●圆形 | 清脆治愈音 |
| 幽紫 `#9B5AE8` | ◆菱形 | 神秘音效 |
| 辉金 `#ECC94B` | ★星形 | 叮当奖励音 |

所有UI必须通过Deuteranopia和Protanopia模拟器验证。

## Section 5: Character Design Direction

- **主角猫**：曲线为主+肩甲锐角，头部占1/3身高确保32px表情可读，默认「蓄势」剪影（重心低、尾巴微弓）
- **敌人分类**（3秒识别）：机械鼠=方形+钢青灰+僵硬节奏；变异生物=有机曲线+荧翠绿弱点；Boss=2-3x体型+幽紫技能光效
- **表情/姿态**：夸张风格。攻击前2帧压缩，受击拉伸1.5x。猫耳角度=状态指示（前倾=攻击，后压=受伤，竖起=探索）
- **LOD**：游戏视距=主轮廓+色块；特写对话=64px精绘+毛发纹理

---

## Section 6: Environment Design Language

- **建筑风格**：旧世界=圆润混凝土（曲线）；机械鼠=铆钉钢板+锐角焊接；交界处锈蚀渐变
- **像素密度**：16x16瓦片基础，前景交互物32px，中景16px，远景8px剪影。禁止同层混用密度
- **道具密度**：枢纽低密度→探索中密度（每3-5屏一个异常物体）→战斗高密度（有序）
- **环境叙事**：无文字规则——墙爪痕=猫族到此，断裂管道+荧翠绿=生命源，锈蚀锁链=旧世界囚笼。每房间至少一个「不问自明」的视觉故事元素

---

## Section 7: UI/HUD Visual Direction

- **HUD**：混合式。战斗信息=屏幕空间圆角矩形（安全港语言）；环境提示=diegetic（猫耳抖动=目标指引，尾巴光效=状态栏）
- **字体**：标题粗圆体（安全+猫主题），数据等宽像素字体。三级：24/12/8px。所有文字#00000080半透明底
- **图标**：描边+微填充（2px描边，1-2色平涂）。技能图标有「蓄力空白」，就绪填充辉金，CD灰化从底部向上恢复
- **动效**：「蓄势」弹出——微缩90%(2帧)→弹出105%→回弹100%(4帧)。菜单过渡=猫爪横扫擦除

## Section 8: Asset Standards

### 1. 文件格式
- **精灵图**: PNG-8（索引色，保持像素锐利）
- **瓦片集**: PNG-32（需透明度通道）
- **动画**: 精灵图表（sprite sheet）格式，帧率12fps基础（攻击动画可提升至24fps）
- **源文件**: Aseprite (.ase) 或 Photoshop (.psd)，保留图层结构

### 2. 命名规范
- 角色精灵: `[character]_[action]_[direction]_[frame].png` (例: `cat_idle_down_01.png`)
- 瓦片: `[biome]_[element]_[variant].png` (例: `rust_floor_cracked_02.png`)
- UI图标: `ui_[category]_[name]_[state].png` (例: `ui_health_bar_fill.png`)
- 特效: `vfx_[type]_[name]_[frame].png` (例: `vfx_hit_spark_03.png`)

### 3. 纹理分辨率层级

| 资产类型 | 最大尺寸 | 内存预算 | 说明 |
|---------|---------|---------|------|
| 角色精灵 | 64x64px | 4KB | 主角/Boss可至96x96px |
| 瓦片 | 16x16px | 1KB | 标准单位，禁止混用尺寸 |
| 前景交互物 | 32x32px | 4KB | 宝箱、开关、NPC |
| UI元素 | 按需 | 2KB | 图标、按钮、边框 |
| 背景层 | 256x256px 平铺 | 16KB | 视差滚动层 |

### 4. LOD策略
- **Level 0 (游戏视距)**: 标准精灵，主轮廓+关键色块
- **Level 1 (特写对话)**: 64px精绘版本，增加毛发纹理、瞳孔细节
- **Level 2 (远景剪影)**: 8px简化版，仅保留轮廓色块

### 5. 导出设置
- **色彩空间**: sRGB
- **透明通道**: 保留Alpha通道（PNG-32）或索引透明（PNG-8）
- **滤镜**: 关闭所有抗锯齿（Nearest Neighbor）
- **压缩**: PNG优化（lossless），目标单个精灵 < 4KB

### 6. 引擎约束 (Godot 4.6.3)
- **纹理过滤**: `texture_filter = Nearest`（像素完美）
- **精灵图集**: 使用 `AtlasTexture` 合批减少Draw Call
- **内存预算**: 2GB(PC) / 1GB(移动端) / 4GB(主机)
- **Draw Call**: 200-300（2D像素艺术）
- **帧预算**: 16.6ms @ 60fps

| 参考 | 取其精华 | 明确避开 | 原因 |
|------|---------|---------|------|
| **空洞骑士** | 精致像素艺术、环境叙事深度、银河城探索结构 |  slower combat pace, single weapon focus | 验证银河城市场，但我们要更快战斗+多武器流派 |
| **恶魔城（月下夜想曲）** | 探索氛围、成长感、Boss战成就感 | 过于线性的关卡结构 | 验证探索+成长循环，但我们要非线性路线选择 |
| **死亡细胞** | 极速流畅战斗、打击感、视觉反馈清晰度 | Roguelite随机性（我们是永久进度） | 验证战斗手感标准，但我们要银河城永久地图 |
| **铳梦（Battle Angel Alita）** | 废土机械美学、小个子战士的反差感、赛博朋克视觉语言 | 过于写实的人体比例（我们是像素风格化） | 验证废土+小战士美学，但我们要卡通化可爱+危险50/50 |
| **风之旅人** | 孤独美感、环境叙事的力量、色彩情感表达 | 无战斗系统、无成长机制 | 验证环境叙事和情感色彩，但我们要战斗+探索双驱动 |

### 视觉方向总结

**《废土喵影》的视觉身份 = 空洞骑士的精致像素 × 死亡细胞的战斗爽感 × 铳梦的废土美学 × 风之旅人的环境叙事 × 猫科动物的敏捷可爱**

独特之处：50%可爱+50%危险的视觉反差，多种武器流派的猫科战斗美学，新旧世界共存的废土环境叙事。
