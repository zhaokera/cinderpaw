# 废土喵影 Cinderpaw

《废土喵影 Cinderpaw》是一款使用 Godot 4 开发的 2D 横版动作银河城游戏。玩家扮演在废土城墟中穿行的猫科猎手，在破碎工业遗迹、阴影巢穴和机械残骸之间探索、战斗、成长，并逐步揭开城市衰败背后的真相。

游戏的核心体验是“敏捷猫科动作 + 废土探索”。玩家通过跳跃、闪避、攻击、弹反和武器切换应对敌人，在紧张的近身战斗中寻找破绽；同时通过新能力解锁路线、发现隐藏区域、强化武器与技能，形成探索、战斗、发现、升级和 Boss 挑战的循环。

## 核心体验

- 横版动作战斗强调移动节奏、闪避窗口、弹反时机和命中反馈。
- 猫科战斗美学突出轻盈身法、快速反击、低血量专注模式和高风险反杀。
- 多武器流派提供不同战斗距离、攻击节奏和特殊机制：猫爪、长尾刃、鱼骨大剑、电磁铃铛。
- 银河城式成长通过探索能力、状态效果、区域门控、奖励系统和 Boss 阶段推动长期推进。

## 世界与视觉

游戏采用废土工业视觉方向，以钢青灰、猫眼金、信号红为主色，结合破败平台、管线、残垣、机械残骸和夕照烟尘塑造末世城墟。角色、敌人与交互物保持清晰剪影，让高速移动、攻击预备、命中反馈和危险提示在复杂背景中仍然易读。

## 当前内容

当前版本包含生成视觉素材、玩家角色、Shadow Beast 敌人、平台场景、生命 HUD、Boss 血条、运行时武器切换、齿轮币显示、暂停/重试菜单、死亡复活循环和基础战斗反馈。项目目标平台以 PC 为主，类型定位为 2D 横版 ACT / 银河城。
