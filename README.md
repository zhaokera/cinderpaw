# 废土喵影 Cinderpaw

《废土喵影 Cinderpaw》是一款使用 Godot 4 开发的 2D 横版动作银河城游戏。玩家扮演在废土城墟中穿行的猫科猎手，在破碎工业遗迹、阴影巢穴和机械残骸之间探索、战斗、成长，并逐步揭开城市衰败背后的真相。

游戏的核心体验是“敏捷猫科动作 + 废土探索”。玩家通过跳跃、闪避、攻击、弹反和武器切换应对敌人，在紧张的近身战斗中寻找破绽；同时通过新能力解锁路线、发现隐藏区域、强化武器与技能，形成探索、战斗、发现、升级、Boss 挑战的循环。

## 游戏特色

- 2D 横版动作战斗，强调移动节奏、闪避窗口、弹反时机和命中反馈。
- 猫科战斗美学，突出轻盈身法、快速反击、低血量专注模式和高风险反杀。
- 多武器流派，猫爪、长尾刃、鱼骨大剑、电磁铃铛对应不同攻击距离、节奏与特殊机制。
- 废土工业视觉，以钢青灰、猫眼金、信号红为主色，结合破败平台、管线、残垣和夕照烟尘塑造末世氛围。
- 银河城式成长，通过探索能力、状态效果、Boss 阶段、区域门控和奖励系统支撑中长期推进。

## 当前可玩切片

当前主场景已经包含生成视觉素材、玩家角色、Shadow Beast 敌人、平台场景、生命 HUD、Boss 血条、运行时武器切换、齿轮币显示、暂停/重试菜单、死亡复活循环和基础战斗反馈。垂直切片正在向更完整的 Boss 战、关卡结构、菜单与存档体验推进。

## 技术信息

- 引擎：Godot 4
- 类型：2D 横版 ACT / 银河城
- 平台目标：PC 优先，后续可扩展到手柄与移动端适配
